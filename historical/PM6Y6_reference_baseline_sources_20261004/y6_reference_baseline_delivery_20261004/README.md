# PM6 Y6 参考基线修正与负结果验证

## 核心结论

四项修正已落实为独立代码：电子/空穴分开的有效 SCLC 迁移率；可数值核验到100 K的 Gaussian–Fermi–Dirac 状态方程；由 PIA 温变密度约束且明确假设条件的复合系数；可分别检查多数载流子库与少数载流子边界的接触实现。旧 Gaussian/Marcus/FF78 代码未覆盖。

这套最小模型 **没有通过论文全温区器件验证**。在100 K，条件性模型得到 Jsc约3.486×10⁻⁶ mA/cm²、Voc约1.10463 V；文献Fig5a读值约0.960 V，S15在0.04 V的光照电流量值约17.9 mA/cm²。后者不是精确Jsc，也不能假定与PIA为同一器件/同一光谱。差异极大，不能通过改称FF78基准或逐温度调接触参数掩盖。数值网格和闭合检查已把该失败与简单积分/离散化错误区分开。

## 参考与参数范围

Perdigón-Toro等，Advanced Energy Materials 12，2103422 (2022)，DOI https://doi.org/10.1002/aenm.202103422。采用提供的原PDF和独立人工核对过的MinerU输出；原始OCR不修改。

- PM6:Y6；参考结构 ITO/PEDOT:PSS/PM6:Y6/PDINO/Ag；活性层110 nm采用SI实验方法。正文器件描述另写100 nm，记录为来源差异，不把两者偷偷混同
- μe(300 K)=8.4×10⁻⁴、μh(300 K)=1.3×10⁻⁴ cm²/(V s)；σe=60、σh=74 meV
- N0=2.4×10²⁰ cm⁻³，是文献DOS模型的假设分子密度；不自动等同于可独立确定跳跃距离的晶格密度
- 完整器件诊断固定Eg=1.42 eV；它是DOS中心能隙，不是光学带隙。另做热力学一致性比较，仅全局拟合一个Eg=1.407221 eV，二者不混用
- SCLC温区约223–328 K。100–200 K计算必须显式allow_mobility_extrapolation=True，否则Device拒绝运行。数值FD能算100 K不代表迁移率在100 K受实验确认
- εr=3.5、两多数接触DOS中心势垒为0、少数接触阻挡或平衡库，全部是条件性情景，非论文确定参数。零势垒意味着多数端c=0.5，为高注入极限；不能称已识别的实际功函数

## 物理闭合与实现

code/fd_eos.py 使用标准正态Gaussian DOS积分c(η)=∫Dz f(η−s z)，s=σ/(kBT)，并计算dc/dη和逆函数。采用801节点Legendre积分、负η半表、粒子空穴对称和稳定稀薄尾部。没有简单移除旧s≤6保护；新数值域独立验证到s=8.7。

code/device.py 使用一维Poisson和双载流子连续性方程。面通量为secant-Einstein Scharfetter–Gummel；g=Δη/Δlnc，均匀化学势电流精确为零。载流子态采用接触参考的准费米势，避免极小暗电流在高导电接触的浮点相消。自适应偏压延拓和边缘加密网格分别处理非线性与接触积累。

有效SCLC迁移率为 μ(T)=μ300 exp[−(4/9)(σ/kB)²(T⁻²−300⁻²)]。负号是对SI S1c源文疑似漏号的明确物理修正；不是声称OCR含该负号。该公式不是严格零密度EGDM。未追加缺乏匹配依据的EGDM密度/场因子：其插值s≈2–6范围在100 K已越界，且GDM拟合的有效零场迁移率与EGDM零密度参数并不自动相同。

复合 R=β(T)np[1−exp(−A)]，A=准费米分裂/(kBT)，满足暗态详细平衡及R A≥0。光生G作为外部不可逆唯象驱动。能量检查是电化学功恒等式，不是完整光子能量/总熵预算。没有无证据的CT/Marcus/陷阱项。

## 校准和留出拆分

1. Table1的μ300/σ和SI N0作材料输入
2. Fig5b的PIA n(T)是校准输入。若固定G，则β(T)/β300=[n300/n(T)]²；β300≈8×10⁻¹² cm³/s来自正文近似值。n(T)被消费为输入后，不能声称模型独立预测了它
3. n300读值3.99168×10¹⁶ cm⁻³给出条件性G0=1.2746807×10²² cm⁻³s⁻¹，110nm生成电流上限22.465 mA/cm²。它低于另一个AM1.5器件统计Jsc24.9 mA/cm²以及S15白光曲线；不同光谱、样品和归一化不能强行合并
4. 固定温区全局Eg的Fig5a比较是再现/一致性检查：均方根残差19.35mV，明显存在温度结构；没有逐T改Eg
5. SI S16的0.5、0.25、0.08sun共27点作为留出。单一全局Eg的绝对Voc RMSE约19.00mV；同温Voc(I)−Voc(1)消除Eg偏移，RMSE约9.79mV，0.08sun仍有明显失配
6. Fig3 BACE是独立条件检验：归一化β(200)/β(300)约0.0458，对比PIA固定G推断约0.1445，相差约3.16倍。不能把它吸收到逐温度自由生成率拟合中。绝对k2也与正文室温锚点不同，样品条件是否同一没有建立
7. S15仅100/300K标签能可靠关联；不把中间色线擅自命名为150/200/250K。CSV保留对数图读出的电流量值，不伪造电流符号

读图误差分别单列；其区间只描述像素读数，不是作者未给出的实验误差。PIA绝对标定、G(T,F)、接触功函数和场增强系数均仍待独立约束。

## 数值与物理状态分开

independent_review/FINAL_VALIDATION.json记录251项通过的定量单元检查：117 EOS、80通量、54器件检查，另有6平衡态；12个641节点光态、6个Voc异号区间端点及1281节点100K Jsc复核。

- EOS最大相对误差：c约1.16×10⁻¹²；dc/dη约4.41×10⁻¹⁰；逆函数约1.03×10⁻¹²
- 321→641节点Jsc差：300K约0.00259%；200K约0.02165%；100K约0.2197%
- 100K 641→1281节点Jsc差约0.0568%，符合接近二阶收敛
- 321与641真实求解Voc差小于约10µV的根定位分辨率；不据此报告多余有效数字
- 每态审计电流展宽、局部连续性L1/L∞、边界电流平衡、Poisson电荷、耗散符号与电化学功
- 门槛包含终端电流相对误差0.1%及显式浮点舍入项，不能只以约0.02A/cm²的总G归一化后给出低温微小电流的“通过”

初版绝对准费米坐标导致错误符号的数值零暗电流，保留在data/archive_absolute_qf_attempt作为失败记录，**不得用于物理解释**。data中N161为探索性过程；最终主结果取重新审计过的N321文件和独立细网格证据。最终源哈希与revalidation字段记录代码版本。接触光生积累使原始体平均n含巨大平衡注入背景，不能直接与PIA光生密度比较。

100K暗态交付快照仅认证已通过最终门槛的点：V=0平衡及0.05–0.975V。0.025V处约10⁻⁴⁰ A/cm²的极小暗电流未通过0.1%相对电流门槛，已标记为未解析且从认证图排除；0.975V以上暗态在交付快照中未完成。不能称100K完整暗态曲线已验证。

## 条件性器件结果

最终数值在data/metrics_summary.csv；Voc和MPP采用额外PDE求解，非仅偏压网格线性插值。100K为找到模型自己的Voc向正偏延伸到1.15V，属于定位失败情景根的诊断，不能说原文验证到1.15V。所有FF均为该条件性场景输出；文献均值66.8%，不是78%。

少数接触阻挡与平衡库、以及1/0.25/0.08相对光强已有独立情景计算；参数没有据此拟合实际接触。实际接触模型尚未通过暗/光/多光强的联合实验校准。当前不能唯一认定差异来自接触、G(T)或输运；但在数值误差已经受控后，应优先取得低温、相近密度与电场下的输运约束，再考虑更复杂机制。

先检查数值与材料状态，再解释物理：无论曲线看起来多接近，都不能把固定G、未定接触、低温迁移率外推变成实验事实。高反偏、PM6:N4指数尾、Marcus参数和热反馈仍不属于这篇Y6基线已验证范围。
