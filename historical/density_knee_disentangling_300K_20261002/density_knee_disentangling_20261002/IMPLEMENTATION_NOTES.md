# 实现修正与记录边界

- 构建新目录时首次启动遇到ModuleNotFoundError: qf_solver。原因是稳定算术脚本依赖相对父目录布局；将原样脚本放入reference/code后修复。该次没有生成解。原始失败日志被随后成功运行覆盖，此处明确记录，不伪称保留原日志。
- 光照前向扫描初版在0 V记录时使用了反偏末点的诊断字典；真正0 V解与端流未错。现代码复用已保存的0 V完整记录，并在指标汇总前将已生成文件的forward_rows[0]替换为同文件rows[0]。所有导出FF和最终验收使用修正后的记录。
- 字体初版图中部分Unicode上标出现方框，已改为兼容的ASCII幂标记并重新渲染、逐图检查。
- 物理参数、势垒公式和速率通道均未为修复这些问题而改变。所有原项目文件保持不变。
- 最终指标复核将预定峰背景明确落实为U±2 V端点曲率较大值，并单独保留SciPy邻近谷底prominence为敏感性对照。两种定义不混用；主峰始终因后端斜率回落而不通过，小峰也不通过严格2 V背景条件。最终CSV/JSON已重新生成。
