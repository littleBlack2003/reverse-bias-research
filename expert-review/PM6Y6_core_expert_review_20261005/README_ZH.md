# PM6:Y6 当前核心模型 · 专家审阅小包

版本：2026-10-05。本包对应当前采用的 **无外部并联电阻、固定室温参数、100–300 K 条件外推** 模型。便于查看方程、核对实现并做小规模数值复查；不是完整计算归档，也不代表模型已获得低温实验验证。

## 先看什么

1. `FORMULA_CODE_MAP.md`：方程、温度律、单位、边界条件与代码位置
2. `code/`：6 份当前实际使用的源文件，逐字保留，无科学模型改写
3. `PARAMETERS.json` 与 `reference/room_fit_frozen.json`：当前参数；主入口为 `extend_device.make_device(T, N)`，不要用 `Device()` 的默认参数代替
4. `review.py`：本次新增便携入口，只调用原模型；`tests/` 是新增轻量检查
5. `optional_candidate_NOT_ADOPTED/`：另行标注的密度依赖候选核心，未被当前模型采用

## 最小运行方法

在解压后的本目录打开终端。已测试：Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0。

```sh
python -m pip install -r requirements.txt
python -B review.py smoke
python -B -m unittest discover -s tests -v
python -B review.py solve --temperature 300 --state sc
python -B review.py solve --temperature 100 --state sc
```

依赖已安装后，以上运行完全离线，不下载数据、不调用服务、不需要原计算目录。安装命令通常需要网络；本包不含虚拟环境或依赖安装包。离线新环境请预先准备对应平台的 NumPy/SciPy 安装包。依赖锁定为本次实测版本，并未宣称任意版本兼容；代码使用 `np.trapezoid`，NumPy 1.x 不适用。勿使用 `python -O`，原代码含用于检查输入的一些 `assert`。

- `smoke`：重新评价 100 K 与 300 K 共 14 个已保存状态的方程残差、守恒和无分流条件；不是从头求解
- `solve`：对一个已保存短路/MPP 状态施加微小扰动后，重新进行非线性求解；仍然依赖随包种子，不是无初值独立收敛证明
- 单元测试：源码一致性、迁移率、FD 状态方程、零亲和力通量、场因子、详细平衡复合与保存状态检查

可选，仅重算两个温度之一的开路根和最大功率点：

```sh
python -B review.py metrics --temperature 300
python -B review.py metrics --temperature 100
```

这是基于小型种子状态的窄范围重新求解，不生成完整 J–V 扫描。300 K 命令已实测；100 K 的该 `metrics` 命令未在此次打包时重新运行，100 K 的保存状态残差与扰动短路求解已实测。跨平台浮点与最优化路径可产生末位及 MPP 电压小差异；不能把优化器电压容差当成物理误差。

## 外电路与旧驱动的区别

当前 Rs=0，外部并联电导严格为 0，Rsh=null。`warm_device.observable` 已明确令 Jsh=0，因此 Jterminal=Jintrinsic。原 `recompute_no_shunt.py` 也保留原样，供专家审阅原计算逻辑，但它需要大型历史种子/结果目录；本小包不具备其完整扫描输入。请通过新增 `review.py` 运行小型复核，不要直接运行旧批量驱动。

`warm_device.py` 还包含历史诊断分支；这些分支存在不表示均为当前模型。`extend_device.py` 中的 WARM 是未使用的历史相对路径，不是便携入口依赖。原代码读取 CSV 的少量未显式关闭文件写法可能触发 ResourceWarning，不影响本次结果；为保持原源码一致未改写。

## 需要专家重点判断

- μ0(T) 来自有效 SCLC/GDM 温度律，并不自动等于零载流子密度的微观迁移率；当前迁移率没有额外 g1(n) 密度增强因子
- FD 占据与广义 Einstein 扩散已包含有限态填充热力学，不能据此宣称已实现密度依赖迁移率
- 场增强包含平滑与 235000 V/cm 截断；低温 γp 的 1/T² 外推、μ0 外推和 β 外推需要各自证据
- 实际净复合是 **R=βnp[1−exp(−A)]**，A 为无量纲电子—空穴准费米分裂；正向大 A 时才近似 βnp。无额外 SRH/CT 项，也未自动强制 Langevin β∝μ
- DOS 中心零势垒多数载流子库和少数载流子阻挡是理想接触假设，不是测得的电极功函数
- 参数固定并不等于已辨识；生成率空间均匀且温度无关，低温几何/材料/接触适用性需实验约束
- 100 K 极小电流是这一模型的预测，不能用数值收敛等同于对真实 PM6:Y6 的解释
